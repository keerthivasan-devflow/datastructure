## Two-Pointer Technique

Definition: Uses two pointers (often left and right) that traverse the data structure (usually an array or string or linked-lists), either in the same direction or from both ends.

Use Case: Problems involving searching, sorting, comparing pairs, or finding distances.

## Typical Pattern:

- Pointers can move independently based on certain conditions.
- Often used in sorted arrays, for example, to find two numbers that sum to a target.
- Where you don't want to create a new array rather in-place should be updated!

## Sorting is required:

- Finding a pair with a specific sum (e.g. sorted array) - Find three/four sum
- Finding closest pair
- Removing duplicates from a sorted array

## The array already has some structure, or sorting would destroy the original relationships, for example:

- Reversing an array using two pointers
- Partitioning the array (like in Quicksort)
- Swapping elements to achieve a condition
- Moving zeroes to the end
- Two-pointer scan on a linked list or matrix
