## Two-Pointer Technique
- To reduce time complexity from O(n²) to O(n) and memory usage
- To efficiently solve problems involving sorted arrays, contiguous subarrays or intervals
- To modify the array in-place

### Classic Problems Solvable By Two Pointers

- **Finding pairs, triplets, or quadruplets matching a sum or difference:**
  - Two Sum in a sorted array
  - Pair Sum in sorted and/or rotated arrays
  - Closest Pair to a target sum
  - Three Sum, Four Sum, and K-Sum (identifying combinations for a specific sum)
  - Count pairs/triplets with a particular absolute difference

- **Moving or Removing Elements Efficiently:**
  - Move Zeroes to End (in-place, maintaining order)
  - Remove Occurrences of an element
  - Remove duplicates (from sorted array)
  - Unique Elements in Sorted Array (deduplicate in place)

- **Merging or Comparing Subarrays:**
  - Merging two sorted arrays
  - Finding intersections/unions of two sorted arrays
  - K-th Element in Merged Sorted Arrays: Efficiently finding the K-th element when two arrays are combined, using two pointers.

- **Reversing or Rearranging:**
  - Reverse an array or string in place
  - Rearrange array in maximum-minimum form alternately
  - Sorting an array of 0s, 1s, and 2s (Dutch National Flag problem)

- **Optimizing/interpreting contiguous subarrays or windowed ranges:**
  - Smallest (or longest) subarray with sum greater than or equal to a value
  - Longest subarray/segment under a sum constraint (sliding window variant)

- **Comparing for Patterns/Special Pattern Recognition:**
  - Palindrome Check - if an array or string is a palindrome
  - Sentence Palindrome (with spaces/characters) - (sentence palindrome, dominant pairs)

- **Specialized Algorithms and Problem Patterns (Optimizing over intervals):**
  - Container with Most Water: Maximizing area using heights at two pointers
  - Trapping Rain Water problem (calculating water between bars)
  - Celebrity problem (finding a node known by all but knowing no one)
  - Intersection with distinct elements (no duplicates)
  - Subarrays with maximal or minimal values within a constraint

**7. Other Applications**
- **Squares of a Sorted Array**: Merge from both ends based on the sorted input array.
- **Dominant Pairs**: Count pairs under specific relational constraints.
- **Celebrity Problem**: Find a node meeting celebrity criteria via elimination.
